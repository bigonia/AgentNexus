### 新增 v2 协议通道 `com.zwbd.agentnexus.sdui.v2`（与旧实现并行，旧端点不变）
- 端点 `/ws/sdui/v2`；旧 `/ws/sdui` 保留用于过渡期回归，P5 阶段删除。
- 协议内核：三种信封（request/result/event）+ 新 8 字节二进制帧头（magic `0x414E`）。
- 会话：`DeviceConnectionRegistry` 用 generation 实现单连接接管与旧连接消息忽略。
- 能力：`CapabilitySchemaV2`、`CapabilityHash`（键排序 JSON → SHA-256 前 16 位）、按 hash 共享缓存 + 同步状态门禁。
- 业务：绑定表模型、双域 token 注册表（`pt_`/`rt_` 严格隔离）、`business.reset/update/trigger`、接管幂等重发。
- 业务面：`display.section/image/canvas`、`audio.*`、`system.*` 全部统一走 request/result。
- 配置上限集中在 `sdui.v2.*`（application.yml 已补默认值）。

### 关键设计裁决（详见 12_DESIGN_NOTES §4）
- 连接接管时旧连接未完成请求立即按 `not_connected` 结束，不等超时。
- v2 不再保留设备微观执行状态（与旧 `SduiDeviceCommand` 的 ACKED/REJECTED 模型相反）。
- Canvas 两层语义：会话级唯一，帧级只保留最新（队列深度 1）+ 丢弃计数。
- 系统命令期望值由平台维护，接管后重发。
- 上报 token 与触发 token 注册表严格分离，防递归。

### 发现的实现缺陷（已修复）
- `BusinessConfigService.validate()` 干跑会签发 token 且成功后不回收 → 改为 `finally` 中全部撤销，补测试固定。

## 环境备忘（本机）
- `./mvnw` 与 `mvn` 在 Git Bash 下均不可用（`MAVEN_HOME` 反斜杠路径被 shell 吞掉导致 classworlds 启动失败）。
  可用替代：
  ```bash
  MVN=/d/software/maven/apache-maven-3.9.6-bin/apache-maven-3.9.6
  java -cp "$(cygpath -w $MVN/boot/plexus-classworlds-2.7.0.jar)" \
       -Dclassworlds.conf="$(cygpath -w $MVN/bin/m2.conf)" \
       -Dmaven.home="$(cygpath -w $MVN)" \
       -Dmaven.multiModuleProjectDirectory="$(cygpath -w $PWD)" \
       org.codehaus.plexus.classworlds.launcher.Launcher -B test
  ```
- maven-compiler-plugin 增量编译会因 `target/maven-status` 不一致而跳过新文件，表现类似"改了代码但报错不变"。
  编译/测试前先 `rm -rf target/maven-status`。
- `target/classes` 偶尔被占用导致 `clean` 失败，只删 `target/maven-status` 与 `target/test-classes` 即可。
- 编辑工具注意：同一文件的多处修改不要放在同一批并发调用里，会互相覆盖。
