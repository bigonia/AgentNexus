# 实施计划（提案）

> **状态**：提案。配合[交付说明](./README.md)使用。

## 1. 交付物拆解

| 编号 | 交付物 | 依赖 |
|---|---|---|
| D1 | 业务模型存储与版本 | 模型字段 |
| D2 | 编辑 API（页面/事件/源/自动化/校验） | D1 |
| D3 | 能力与触发器注册表 | 契约 |
| D4 | 编译器（模型 → 终端消息） | D1、D3、终端协议 |
| D5 | 运行期编排器（步骤/值/超时/错误） | D3、D4 |
| D6 | 设备接入与事件分发 | 终端协议 |
| D7 | 外部 provider 调用 | D3 |
| D8 | MCP Server + 本地桥 + Skill | D2、D3 |
| D9 | 观测与审计 | 全部 |

## 2. M1：确定性最小链路

**目标**：用假实现跑通 `源 → 转换 → 页面 → 执行器`，全程确定性、可测。

**任务**

- [ ] D1：模型存储（文件或简单表即可），含单页模型；
- [ ] D4：编译器生成 `business.scenes.replace` + `display.section.set`；
- [ ] D6：接收终端 `platform.interaction` 事件；
- [ ] D5：线性执行 2~3 步，invocation 值传递；
- [ ] 一个 **mock executor**（固定返回文本）；
- [ ] 单页 + 按钮录音 + mock 回显到页面。

**验收**

- 终端按键 → 录音 → 停止 → mock 结果渲染到页面，全链路可复现；
- 重启平台后重复上述流程结果一致；
- 无跨作用域状态、无外部依赖。

## 3. M2：外部能力与触发器

**目标**：把 mock 换成真实外部能力，接口不变。

**任务**

- [ ] D3：能力契约注册（至少 `ai.stt` / `ai.dialog` / `ai.tts` 的契约）；
- [ ] D7：provider 调用（HTTP 优先），含超时与错误映射；
- [ ] D5：失败走 `on_error`；
- [ ] 触发器注册契约 + 接收端点 + 幂等；
- [ ] 用真实外部 AI 替换 mock，模型不改。

**验收**

- 同一模型不修改即可切换 provider；
- provider 超时/报错时终端显示错误页，不卡死；
- 重复投递同一触发器（同幂等键）不产生重复渲染。

## 4. M3：Agent 接入

**目标**：Agent 可通过本地桥编写与部署业务。

**任务**

- [ ] D2：编辑 API（意图级操作）；
- [ ] D8：MCP Server（把编辑 API 暴露为 MCP 工具）；
- [ ] D8：本地桥（stdio MCP + 主动出站连接 + 认证）；
- [ ] Skill（`SKILL.md` + 由 UI Schema/能力契约生成的参考）；
- [ ] 校验返回机器可读错误；
- [ ] （可选）会话/多轮。

**验收**

- Agent 能完成"选择能力 → 配页面 → 校验 → 部署"闭环；
- 校验错误可被 Agent 修正后通过；
- 部署是显式动作，保存不生效。

## 5. 依赖

- 终端协议 `lcd085.v2`（已定）；
- 设备可连接（WebSocket）；
- 外部 AI 服务可用（M2 起）；
- Agent 运行环境（M3 起）。

## 6. 风险

| 风险 | 说明 | 应对 |
|---|---|---|
| 运行期并发/重入 | 连按、重复触发 | v1 单设备单流程，多余丢弃 |
| 断线对账 | 流程仍在跑，设备断线 | v1 断线中止，重连回入口页 |
| 外部 provider 不可靠 | 超时、错误 | 契约强制 `timeout_ms`/`errors`，明确失败 |
| 模型/能力契约漂移 | 文档与实现不一致 | 契约单一事实来源，生成 Skill 参考 |
| 范围蔓延 | 想做成通用引擎 | 严格执行[非目标](./README.md#5-明确非目标防止范围蔓延) |

## 7. 里程碑总览

```text
M1 确定性链路（无外部依赖）
  └─► M2 外部能力 + 触发器
        └─► M3 Agent 接入 + （可选）会话
```
